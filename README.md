# Analisis Penurunan IHSG dan Faktor-Faktor yang Memengaruhinya

## Deskripsi

Repository ini merupakan proyek analisis mengenai penurunan Indeks Harga Saham Gabungan (IHSG) dan faktor-faktor yang memengaruhinya.

Proyek ini dilakukan melalui proses pengumpulan data, pengolahan data, analisis, serta visualisasi untuk mengetahui kondisi dan faktor yang berkaitan dengan pergerakan IHSG.

## Tujuan

Tujuan dari proyek ini:
- Untuk mengetahui kondisi dan pola pergerakan IHSG.
- Mengidentifikasi faktor yang dapat memengaruhi penurunan IHSG.
- Melakukan pengolahan dan analisis data menggunakan Python.
- Menyajikan hasil analisis dalam bentuk visualisasi.

## Teknologi yang Digunakan

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- GitHub
